# 🎓 Educational Project: IT Support & Web Development

Welcome to the official repository for this learning project! 

This repository is an educational project designed for teaching and hands-on training in **IT Support**, **Web Development**, and **Collaborative Software Development using GitHub**.

---

## 🎯 Purpose & Learning Objectives

The main goal of this repository is to give students practical experience with real-world development workflows, IT support processes, and team collaboration tools.

Through this project, students will learn:
- **Web Development:** Build, debug, and maintain web applications and interface components.
- **IT Support & Systems:** Understand deployment, environment setup, troubleshooting, and issue resolution.
- **Git & GitHub Collaboration:** Master branch management, Pull Requests, code reviews, and issue tracking.

---

## 🔄 Collaboration & Workflow Guidelines

To ensure a smooth learning environment and maintain code quality on the primary branch (`main`), all students must follow this workflow:

### 1. Working with Branches
- **Do NOT push directly to `main`.** The `main` branch is protected and reserved for approved code.
